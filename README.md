# App Store Reports Dashboard

A local, dependency-free dashboard for pulling App Store Connect Sales & Trends reports into files on your machine and exploring them in a browser.

## What It Captures

- Daily Summary Sales reports from `/v1/salesReports`
- Units, customer sales, proceeds, country, product type, app title, SKU, and Apple ID
- Downloaded tab-delimited reports in `data/sales-reports`
- Parsed normalized rows in `data/sales-state.json`
- CSV export at `/api/sales/export.csv`

Sales & Trends reports are generated by Apple and are usually available the next day. Daily, weekly, and monthly reports are only retained for one year.

## Setup

1. Create an App Store Connect API key in App Store Connect with access to Analytics.
2. Copy `.env.example` to `.env`.
3. Put your private key beside this app, or point `ASC_PRIVATE_KEY_PATH` to it.
4. Fill in:

```bash
ASC_ISSUER_ID=your-issuer-id
ASC_KEY_ID=your-key-id
ASC_PRIVATE_KEY_PATH=./AuthKey_your-key-id.p8
ASC_VENDOR_NUMBER=your-vendor-number
PORT=4173
ASC_SALES_DAYS=30
```

You can also use `ASC_PRIVATE_KEY` with escaped newlines instead of a file path.

Find your vendor number in App Store Connect under **Payments and Financial Reports** or in Sales and Trends report settings. Sales & Trends endpoints require a Team API key with suitable access, such as Sales and Reports, Finance, Admin, or Account Holder.

## Run

```bash
npm start
```

Open:

```text
http://localhost:4173
```

Click **Sync Sales & Trends** to download recent daily Summary Sales reports for your vendor number.

## Files

- `src/server.js` signs App Store Connect JWTs, syncs Sales & Trends reports, stores local data, and serves the API.
- `public/index.html` is the dashboard shell.
- `public/app.js` renders Sales & Trends status, app totals, daily units, metrics, raw rows, and CSV export.
- `public/styles.css` contains the responsive visual system.
- `data/sales-reports` stores downloaded Sales & Trends reports.
- `data/sales-state.json` stores normalized dashboard state.

## Notes

- Keep `.env`, `.p8`, and `data/` private; they are ignored by git.
- Apple report availability depends on App Store Connect permissions and report preparation status.
- This app intentionally uses only built-in Node.js APIs, so there is no install step.
